# שלב 17: סרטון פרסומת (30 שניות)

## 1. מה נבנה

- **ארבע גרסאות:** עברית ואנגלית, כל אחת לרוחב (‎1920×1080, ל-YouTube, לאתר ול-README) ולגובה (‎1080×1920, ל-Reels, TikTok ו-Stories).
- **מוזיקה מקורית:** נוצרת בקוד (סינתזה), בלי זכויות של צד שלישי.
- **כלי שמייצר אותן מחדש:** `pnpm --filter @rubinny/showcase ad`, כך שאחרי כל שינוי בממשק אפשר להפיק סרטון מעודכן.

## 2. איך זה עובד

1. **עמוד HTML אחד** (`apps/showcase/src/ad/ad.html`) מכיל את כל הסצנות. כל תנועה בו היא פונקציה של הזמן (`window.seek`), והשפה והפורמט נבחרים בפרמטרים.
2. **צילום פריים אחר פריים:** הסקריפט (`ad.mjs`) מציב את העמוד בזמן מדויק לכל פריים (30 בשנייה) ומצלם אותו. כך כל פריים יוצא חד וזהה בכל הרצה, בלי תלות במהירות המחשב.
3. **מוזיקה:** `music.mjs` מסנתז קובץ WAV: אקורדים רכים, ארפג'ו ותוף עדין, עם כניסה ויציאה הדרגתיות.
4. **קידוד:** ffmpeg מחבר את הפריימים והמוזיקה ל-MP4 ‏(H.264 ו-AAC, ‏`faststart` לניגון מיידי ברשת), ומפיק גם תמונת פוסטר.

## 3. התסריט

| זמן   | סצנה                     | טקסט (עברית)                                     |
| ----- | ------------------------ | ------------------------------------------------ |
| 0–3   | פתיחה                    | המסכים שלכם. התוכן שלכם.                         |
| 3–7   | הלוגו                    | Rubinny: שילוט דיגיטלי חינמי בקוד פתוח           |
| 7–12  | ערכות מוכנות             | ערכה מוכנה לכל עסק: מסעדה, בית קפה, קולנוע, חנות |
| 12–16 | עורך העיצוב ועורך התפריט | מעצבים בקלות: תפריטים, מחירים, מבצעים            |
| 16–20 | תזמון                    | התוכן הנכון בשעה הנכונה                          |
| 20–24 | ניהול המסכים             | כל המסכים במקום אחד, ונגנים לכל מכשיר            |
| 24–27 | השרת שלכם                | מתקינים על השרת שלכם. הנתונים נשארים אצלכם.      |
| 27–30 | סיום                     | Rubinny · חינם וקוד פתוח · הקישור ל-GitHub       |

כל הטענות בסרטון נכונות לגרסה 0.7.1. אין בו טענות על עמידה בתקן או בחוק.

## 4. נגישות ופרטיות

- **טקסט:** גדול (לפחות 48px ב-1080p), בניגודיות גבוהה, ומוצג לפחות 2.5 שניות.
- **בלי הבהובים:** אין יותר משלושה הבהובים בשנייה.
- **הסרטון שקט מבחינת תוכן:** כל המידע מופיע כטקסט, ולכן אפשר לצפות בו גם בלי קול.
- **פרטיות:** התמונות הן מארגון הדגמה (שמות בדויים). אין בסרטון מידע אישי אמיתי.
