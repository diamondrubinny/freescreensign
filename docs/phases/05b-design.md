# שלב 5b — עיצוב, תבניות ופיצ'רים מבוקשים

**מטרה:** מראה מקצועי ואחיד ללוח הניהול ולמסכים, תבניות מוכנות שמאפשרות להתחיל בדקה, והפיצ'רים שמשתמשי מערכות שילוט מבקשים הכי הרבה.

## הנחות עבודה

- "פיצ'רים מבוקשים" = הפיצ'רים הנפוצים אצל מתחרים שעוד חסרים אצלנו. הרשימה בסעיף 4.
- העיצוב נשאר נגיש (WCAG 2.1 AA), RTL-first, עם מצב כהה, ובלי פניות לשרתים חיצוניים. הגופן ארוז יחד עם האתר.

## 1. מערכת עיצוב (CMS)

| נושא | החלטה | חלופות |
|---|---|---|
| גופן | **Heebo** (‏OFL), ‏`@fontsource-variable/heebo`, נארז מקומית ומותר לפי ה-CSP (`font-src 'self'`) | Assistant, Rubik |
| אייקונים | **lucide-react** (‏ISC). רק האייקונים שבשימוש נכנסים לבאנדל. כל האייקונים דקורטיביים (`aria-hidden`), והטקסט נשאר | Heroicons |
| צבעים | Tokens ב-`@theme` של Tailwind: צבע מותג אינדיגו-סגול, משטחים, גבולות. ניגודיות ≥ 4.5:1 בבהיר ובכהה | — |

**רכיבים:** ‏`Card`, ‏`EmptyState`, ‏`Badge`/`StatusPill`, ‏`PageHeading` עם תיאור ופעולות, ‏`Button` עם אייקון, וסגנון שדות אחיד.

**מעטפת:**
- סרגל צד עם אייקונים וקבוצות: תוכן, מכשירים, ארגון.
- בנייד: תפריט נפתח (כפתור עם `aria-expanded`).
- כותרת עליונה דביקה.

**עמודים:**
- לוח בקרה עם נתונים: מסכים מחוברים, פלייליסטים, מדיה, תבניות.
- פעולות מהירות ורשימת "צעדים ראשונים".
- רשימות כ-כרטיסים עם תצוגה מקדימה: מיניאטורה של אזורי התבנית, ואייקון לכל סוג Widget.

## 2. תבניות

- **תבניות Layout נוספות:** כותרת + ראשי + פס תחתון, רשת 2×2, ראשי + צד ימני, ושלוש שורות (לאורך).
- **בוחר תבניות ויזואלי:** כפתורי רדיו טבעיים עם שרטוט של האזורים, כך שהוא נגיש במקלדת ובקורא מסך.
- **ערכות מוכנות (Starter kits):** לחיצה אחת יוצרת Widgets, פלייליסטים ותבנית מעוצבים ומחוברים, בטרנזקציה אחת בשרת. הטקסטים נוצרים בשפת המשתמש.
  - **לובי:** אזור ראשי למדיה, שעון עם תאריך עברי, טקסט רץ ו-QR.
  - **שלט מידע / תפריט:** כותרת, טקסט ושעון.
  - **קבלת פנים במשרד:** ברוכים הבאים, שעון ו-QR ל-Wi-Fi או לאתר.

## 3. מסך (נגן)

- גופן Heebo בנגן. הוא נשמר לעבודה Offline יחד עם שאר הקבצים.
- **עיצוב Widgets מחודש:**
  - שעון בכרטיס.
  - טקסט רץ עם תווית (למשל "עדכונים").
  - טקסט עם כותרת.
  - RSS עם נקודות התקדמות.
  - מזג אוויר בכרטיסים.
  - QR בכרטיס מעוגל.
- **התאמת מדיה לאזור** (לכל פריט בפלייליסט):
  - **התאמה** (`contain`).
  - **מילוי** (`cover`).
  - **רקע מטושטש:** התמונה כולה, ומאחוריה עותק מטושטש שלה במקום פסים שחורים.

## 4. פיצ'רים מבוקשים

1. **שכפול** פלייליסט, תבנית ו-Widget.
2. **Widget ספירה לאחור** (לאירוע או לחג), עם הודעת סיום.
3. **התאמת מדיה** (סעיף 3).
4. **ערכות מוכנות** (סעיף 2).

## 5. שינויי נתונים ו-API

- **Migration ‏`0005_item_fit`:** ‏`playlist_items.fit` ‏(`contain` | `cover` | `blur`, ברירת מחדל `contain`).
- **Manifest:** ‏`fit` אופציונלי בפריט. נגן ישן מתעלם ממנו (תאימות לאחור).
- **API:**
  - `POST …/playlists/:id/duplicate`
  - `POST …/layouts/:id/duplicate`
  - `POST …/widgets/:id/duplicate`
  - `POST …/starter-kits/:kit` (‏EDITOR)
- **סכמות Widgets:** `countdown` חדש; `label` אופציונלי ל-ticker; `title` אופציונלי ל-text.

## 6. בדיקות

- יחידה: תבניות חדשות מכסות את הקנבס, סכמת countdown.
- Integration: שכפול (כולל IDOR), ערכות מוכנות, ‏`fit` ב-Manifest.
- נגן: countdown, ‏`fit` ו-blur.
- CMS: בוחר התבניות וערכות.
- ‏E2E + axe על כל העמודים המעוצבים, וצילומי מסך לבדיקה ויזואלית.
