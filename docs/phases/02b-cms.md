# שלב 2b — CMS: שלד, חשבונות וארגונים ✅

## 3. נגישות (WCAG 2.1 AA / ת"י 5568)

- HTML סמנטי, Landmarks (`header`, `nav`, `main`, `footer`) וקישור "דלג לתוכן".
- בכל מעבר עמוד: הפוקוס עובר ל-`h1` וה-`document.title` מתעדכן.
- טפסים:
  - `label` לכל שדה.
  - שגיאות מקושרות לשדה (`aria-describedby` + `aria-invalid`).
  - סיכום שגיאות עם `role="alert"`.
- מצבי טעינה והודעות הצלחה דרך `aria-live`.
- ניגודיות ≥ 4.5:1, Focus ring בולט, ותמיכה ב-`prefers-reduced-motion`.
- **תפריט התאמות נגישות:** הגדלת טקסט, ניגודיות גבוהה, הדגשת קישורים, גופן קריא ועצירת אנימציות. ההגדרות נשמרות ב-`localStorage`. התפריט הוא כלי עזר בלבד, ולא תחליף לנגישות בקוד.
- **בדיקות:** axe-core על כל עמוד ב-Playwright, בעברית ובאנגלית.

## 4. פרטיות ועוגיות

- **אין עוגיות שאינן חיוניות, אין Analytics ואין סקריפטים צד שלישי.** לכן לא מוצג באנר עוגיות. אין חובה כזו כשמשתמשים רק בעוגיות חיוניות — **דורש אימות משפטי**.
- **בכל עמוד, ב-Footer:**
  - קישור קבוע "הגדרות פרטיות ועוגיות", שפותח חלון עם רשימת העוגיות ואחסון ההעדפות.
  - הקרדיט **"Powered by Rubinny"** עם קישור לקוד, כנדרש ב-`LICENSING.md` (סעיף 7(b)).
- **תשתית `consent`** (קטגוריות, גרסת מדיניות, תאריך) מוכנה למפעיל שירצה להוסיף כלים. כל כלי כזה ייטען רק דרכה, ורק אחרי הסכמה.

## 5. אבטחה בצד הלקוח

- **CSP קשיח מ-Caddy:**
  - ‏`default-src 'self'`, ‏`script-src 'self'`, ‏`style-src 'self'`.
  - ‏`img-src 'self' data:`.
  - ‏`connect-src 'self'`, ‏`frame-ancestors 'none'`.
  - ‏`base-uri 'none'`, ‏`form-action 'self'`.
- **בלי `dangerouslySetInnerHTML`** (נאכף ב-ESLint).
- **טוקנים מה-`#fragment`:** נקראים ומיד נמחקים מה-URL (`history.replaceState`).
- **ה-Session** נשמר ב-HttpOnly cookie בלבד. אין tokens ב-JS או ב-localStorage.
- **Cache:** ‏`index.html` ללא cache. ה-assets עם hash מקבלים `immutable`.

## 6. פריסה

- **Image חדש `rubinny/web`:** Caddy עם ה-build הסטטי של ה-CMS. מחליף את `caddy:2-alpine` ב-Compose.
- **פיתוח:** ‏`pnpm --filter @rubinny/cms dev` (Vite), עם proxy ל-`/api` → ‏`localhost:3000`. בצד השרת מגדירים `PUBLIC_URL=http://localhost:5173`, כדי שבדיקת ה-Origin תעבור.

### באגים שנמצאו ותוקנו בזכות הבדיקות

1. **מוזמנים לא יכלו להתחבר כשה-SMTP כבוי** (ברירת המחדל): לא הייתה להם דרך לאמת את האימייל. מעכשיו אימות אימייל נאכף רק כשהשרת מסוגל לשלוח דואר. בלי SMTP, המנהל מעביר את קישור ההזמנה אישית, והכתובת נשמרת כ"לא מאומתת" (`email_verified_at = null`). נוספה בדיקת Integration.
2. **הודעה מטעה ב-MFA:** קוד שגוי הציג "האימייל או הסיסמה שגויים". מעכשיו מוצגת הודעה ייעודית לקוד שגוי.
3. **אזהרת `HydrateFallback`:** הופיעה בכניסה ישירה לעמוד שנטען לפי דרישה. תוקן.
