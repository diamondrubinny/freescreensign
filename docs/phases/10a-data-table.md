# שלב 10א — Widget טבלת נתונים (CSV, ‏Google Sheets, ‏JSON)

## 1. מטרה

תפריטים, מחירונים, לוחות זמנים ותורנויות מתעדכנים במסכים לבד. מעדכנים גיליון, והמסכים מתעדכנים תוך כמה דקות, בלי להיכנס למערכת.

## 2. User Stories

1. **בעל מסעדה:** מעדכן מחיר בגיליון Google, והמחיר במסך מתעדכן תוך 5 דקות.
2. **רכזת בבית ספר:** מציגה את רשימת התורנויות מקובץ CSV שמתפרסם באתר בית הספר.
3. **מפתח:** מחבר כתובת JSON (מערך אובייקטים), ובוחר אילו עמודות יוצגו ובאיזה סדר.
4. **עורך:** רואה תצוגה מקדימה של הנתונים בדיוק כפי שהמסך יקבל אותם, לפני שהוא משייך את ה-Widget לפלייליסט.
5. **צופה מול המסך:** טבלה קריאה מרחוק. כשיש יותר שורות ממה שנכנס במסך, מוצגים עמודים מתחלפים.

## 3. הגדרות ה-Widget (`type: "table"`)

| שדה              | ערך                                                 | ברירת מחדל               |
| ---------------- | --------------------------------------------------- | ------------------------ |
| `source`         | `csv` או `json`                                     | `csv`                    |
| `url`            | כתובת http או https                                 | חובה                     |
| `jsonPath`       | נתיב בנקודות למערך בתוך ה-JSON (למשל `data.items`)  | ריק = השורש              |
| `hasHeader`      | האם השורה הראשונה ב-CSV היא כותרות                  | `true`                   |
| `columns`        | עמודות להצגה, מופרדות בפסיקים, לפי הסדר             | ריק = כל העמודות (עד 12) |
| `title`          | כותרת מעל הטבלה                                     | ריק                      |
| `rowsPerPage`    | 1–20                                                | 8                        |
| `pageDurationMs` | 3–60 שניות                                          | 10                       |
| `maxRows`        | 1–200                                               | 50                       |
| `refreshMinutes` | 1–1440                                              | 5                        |
| `locale`         | `he` או `en`: כיוון הטבלה                           | `he`                     |
| צבעים            | `textColor`, ‏`background`, ‏`accent` (רקע הכותרות) | ערכת ברירת מחדל          |

### Google Sheets

- **כתובת פרסום:** מ"קובץ ← שיתוף ← פרסום באינטרנט ← CSV" מתקבלת כתובת `…/pub?output=csv`, שעובדת כמו שהיא.
- **כתובת עריכה:** כתובת עריכה רגילה (`…/spreadsheets/d/<id>/edit#gid=<n>`) מומרת אוטומטית לכתובת הייצוא `…/export?format=csv&gid=<n>`. זה עובד רק לגיליון ששותף כ"כל מי שיש לו את הקישור".
- **אימות:** ההתנהגות של Google בשתי הכתובות **דורשת אימות מול התיעוד הרשמי** ובדיקה ידנית. ההפניות (redirects) שלה ל-`googleusercontent.com` עוברות דרך `safe-fetch`, שבודק כל הפניה מחדש.

## 4. ארכיטקטורה

הזרימה זהה לזו של RSS ומזג אוויר, בלי טבלה חדשה במסד ובלי מיגרציה:

```
Player ──GET /player/v1/widgets/:id/data──► Server ──safeFetch──► CSV/JSON source
                                              │
                                              └─► Valkey cache (fresh = refreshMinutes, stale ≤ 24h)
```

**השרת:**

- `table.ts`: מנתח CSV לפי RFC 4180, כולל מירכאות, שורות חדשות בתוך תא, BOM וזיהוי אוטומטי של המפריד (`,` `;` או Tab). מנתח JSON ומחלץ ממנו טבלה.
- את התשובה הוא מנרמל ל-`{ columns: string[], rows: string[][], truncated: boolean }`.

**הנגן:** טבלה סמנטית (`<table>` עם `<th scope="col">`), עמודים מתחלפים, וכיוון לפי השפה. כל תא מקבל `dir="auto"` כדי שעברית ומספרים יוצגו נכון.

**מסך הניהול:** טופס לפי `WIDGET_FIELDS`, ותצוגה מקדימה של הטבלה.

## 5. Threat Model קצר

| איום                                                      | בקרה                                                                                                                    |
| --------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| ‏SSRF לכתובות פנימיות                                     | `safeFetch`: בודק כל כתובת IP בזמן החיבור, מאפשר רק פורטים ברירת מחדל, ובודק מחדש כל הפניה                              |
| קובץ ענק או "פצצת דחיסה"                                  | תקרה של 1MB אחרי פריסת הדחיסה, ‏Timeout של 5 שניות                                                                      |
| ‏CSV או JSON שמכבים את השרת (מבנה עמוק או מספר תאים עצום) | תקרות: 200 שורות, 12 עמודות, 300 תווים לתא. ‏`jsonPath` מוגבל ל-10 רמות. ‏JSON מתפרש עם `JSON.parse` בלבד, בלי הרצת קוד |
| ‏XSS בנגן או במסך הניהול                                  | התוכן מוצג כטקסט בלבד (`textContent`, ‏React). השרת מסיר תגיות ותווי בקרה                                               |
| ‏CSV Injection (נוסחאות)                                  | לא רלוונטי: הנתונים לא מיוצאים לגיליון. מוצגים כטקסט בלבד                                                               |
| הצפת המקור החיצוני                                        | מטמון משותף לכל ה-Widgets שמשתמשים באותו מקור. מגבלת קצב לארגון (`widgetFetchOrg`). המתנה של דקה אחרי כישלון            |
| ‏IDOR                                                     | אותם guards כמו בשאר ה-Widgets: נגן רק לארגון שלו, ‏`orgGuard` במסך הניהול, ובדיקת בידוד ארגונים בעליית השרת            |

## 6. פרטיות

- **מידע אישי:** הטבלה יכולה להכיל מידע אישי, למשל שמות תורנים. הארגון מחליט מה לפרסם. **המסך מוצג בפומבי.** ההנחיה בטופס מזהירה מכך.
- **אחסון:** עותק הנתונים נשמר ב-Valkey עד 24 שעות (לשימוש כשהמקור לא זמין), ונמחק אוטומטית.
- **צד שלישי:** המקור (למשל Google) מקבל בקשה מכתובת השרת בלבד, בלי פרטי משתמשים או מסכים. נוסף לטבלת הצדדים השלישיים ב-PLAN.

## 7. נגישות

- טבלה עם כותרות עמודה אמיתיות, בצד הנגן ובתצוגה המקדימה במסך הניהול (`<caption>` ו-`<th scope="col">`).
- ניגודיות צבעי ברירת המחדל לפי AA.
- כשמוגדרת אצל המשתמש העדפה להפחתת תנועה (`prefers-reduced-motion`), העמודים מתחלפים בלי אנימציה.

## 8. בדיקות

- **יחידה:** ‏CSV (מירכאות, שורה חדשה בתוך תא, BOM, `;`, Tab, תאים חסרים או עודפים, תקרות); ‏JSON (נתיב, מערך מערכים, מערך אובייקטים, ערכים לא תקינים); בחירת עמודות; המרת כתובת Google Sheets.
- **‏API:** יצירה וולידציה; נתונים לנגן מתוך שרת בדיקה מקומי; מטמון.
- **נגן:** רינדור עמודים.
- **‏E2E:** כמו בשאר ה-Widgets.

## 9. תוצאות

- **שרת:** ‏`modules/widgets/table.ts` (מנתח CSV ו-JSON, בחירת עמודות, המרת קישור Google Sheets). משולב ב-`data.ts` עם רענון לפי `refreshMinutes`.
- **נגן:** ‏`widgets/table.ts`. כל ערך עטוף ב-`<bdi>`, כך שאנגלית ומחירים בטבלה מימין לשמאל מיושרים לפי הטבלה ולא נגררים לצד השני. נבדק בצילום מסך בשני גדלי אזור.
- **מסך הניהול:** שדות הטופס, הערת פרטיות ותצוגה מקדימה כטבלה נגישה (`TableRegion`).
- **בדיקות:**
  - 13 בדיקות יחידה (`test/widgets/table.test.ts`).
  - בדיקת API: ‏CSV בעברית עם `;` ו-BOM, ו-JSON בנתיב עם חיתוך.
  - בדיקת נגן: עמודים, כותרות `th`, וטקסט בלבד בלי HTML.
  - ‏E2E: יצירה ו-axe לטופס.
- **פתוח:**
  - בדיקה ידנית מול Google Sheets אמיתי: **דורש אימות מול התיעוד הרשמי**.
  - ה-E2E לא מושך נתונים, כי בסביבת הייצור אסור למשוך מכתובות פנימיות.
