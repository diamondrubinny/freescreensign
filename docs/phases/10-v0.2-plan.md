# גרסה 0.2 — תוכנית (טיוטה לאישור)

## 1. מאיפה ממשיכים

‏v0.1.0 מוכנה, כטיוטת Release.

**נדחו ל-0.2:**

- ‏RLS במסד הנתונים.
- ‏images ל-arm64.
- חתימת קוד.
- בדיקה על חומרה אמיתית.

**לפי ה-Roadmap:**

- **שלב 10:** ‏Samsung Tizen ו-LG webOS.
- **‏D5:** אינטגרציות נתונים, Touch, ‏Video Wall, ‏AI, חירום, ‏SSO.

## 3. המלצה

**סדר מומלץ:** ג ← ד ← א ← ב.

1. **ג ו-ד:** נותנים את הערך הכי גדול למשתמשים, והכי קל לוודא שהם עובדים.
2. **א:** משפר אבטחה בלי לשנות התנהגות. כדאי לסגור לפני מפעילים גדולים.
3. **ב:** יוצא רק כשיהיה מכשיר Samsung או LG לבדיקה. בלי מכשיר אי אפשר להבטיח שזה עובד.

## 4. לכל מסלול, לפני בנייה

- **אפיון:** ‏User Stories, מסכים, ‏API, מיגרציה ו-Threat Model קצר.
- **מידע אישי וצדדים שלישיים:** עדכון טבלת המידע האישי ורשימת הצדדים השלישיים. למשל, Google Sheets הוא ספק חדש.
- **בדיקות:** יחידה, ‏API, ‏E2E ו-axe, באותה רמה כמו בגרסה 0.1.
