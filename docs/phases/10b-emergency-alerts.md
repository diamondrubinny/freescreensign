# שלב 10ב — התראות חירום

## 1. מטרה

בלחיצה אחת במסך הניהול, כל המסכים של הארגון (או מסכים נבחרים) מחליפים מיד את התוכן בהודעה בולטת. ההודעה נשארת עד שמבטלים אותה, או עד שעובר זמן שנקבע מראש.

## 2. User Stories

1. **מנהלת בית ספר:** מפעילה "פינוי מיידי" מהטלפון, וכל המסכים בבית הספר מציגים את ההודעה תוך שניות.
2. **אחראי בטיחות:** שולח הודעה רק למסכים של בניין ב'.
3. **עורך:** מסיים את ההתראה, והמסכים חוזרים מיד לתוכן הרגיל.
4. **עורך:** קובע התראה זמנית ("הכניסה הראשית סגורה" לשעה), והיא נעלמת לבד גם ממסך שאיבד חיבור.
5. **מנהל:** רואה ביומן הביקורת מי הפעיל כל התראה, מי סיים אותה ומתי.

## 3. החלטות

**התראה = שכבה מעל הכול:**

- ההתראה לא נכנסת לפלייליסטים. הנגן מציג אותה כשכבה על כל המסך.
- התוכן ממשיך לרוץ מתחת לשכבה, כך שכשההתראה מסתיימת המסך ממשיך בלי טעינה מחדש. הווידאו בנגן מושתק תמיד.

**שני סגנונות:**

| סגנון       | מראה                                                                           | שימוש                   |
| ----------- | ------------------------------------------------------------------------------ | ----------------------- |
| `emergency` | אדום, סמל אזהרה, הבהוב עדין (ללא הבהוב כשמוגדרת אצל המשתמש העדפה להפחתת תנועה) | פינוי, מרחב מוגן, נעילה |
| `notice`    | כתום-צהוב                                                                      | הודעה דחופה שאינה חירום |

**מסירה מהירה:**

1. השרת שולח `manifest.changed` ב-WebSocket למסכים הרלוונטיים.
2. הנגן מושך את ה-Manifest ומציג את ההתראה **מיד**, לפני ההורדה של מדיה חדשה (הורדה כזו יכולה לקחת דקות).
3. ההתראה נשמרת גם בזיכרון המקומי של הנגן, כך שהיא מוצגת גם אחרי הפעלה מחדש בלי רשת.

**סיום אוטומטי:**

- `endsAt` הוא רשות.
- **השרת** מפסיק לשלוח התראה שפג תוקפה.
- **הנגן** מסתיר אותה לבד לפי השעון המתוקן (תיקון סטיית שעון כבר קיים), גם בלי רשת.

**תבניות:** "פינוי מיידי", "היכנסו למרחב המוגן", "נעילה (Lockdown)" ו"הודעה כללית". התבניות ממלאות את הטופס, ואפשר לערוך את הטקסט.

**הרשאות:**

- `EDITOR` ומעלה: הפעלה וסיום.
- `VIEWER`: צפייה בלבד.
- **אין דרישה ל-MFA** לפעולה הזו, כי במצב חירום אסור לעכב. הפעולות נרשמות ביומן הביקורת.

**מחוץ להיקף:** חיבור אוטומטי להתרעות פיקוד העורף. **דורש אימות מול התיעוד הרשמי** של ממשק פיקוד העורף ותנאי השימוש בו, **ובדיקה משפטית**.

## 4. מודל נתונים (מיגרציה `0010_alerts`)

```
alerts
  id uuid PK
  org_id uuid FK → orgs (cascade)
  style text CHECK IN ('emergency','notice')
  title text (1–120)
  message text (0–500)
  screen_ids uuid[] NULL      -- NULL = every screen of the organization
  starts_at timestamptz DEFAULT now()
  ends_at timestamptz NULL    -- NULL = until ended
  ended_at timestamptz NULL
  created_by uuid FK → users (set null)
  ended_by uuid FK → users (set null)
  created_at timestamptz
INDEX (org_id) WHERE ended_at IS NULL
```

**מקסימום 20 התראות פעילות לארגון.** מסך שמכוסה בכמה התראות מציג את החדשה ביותר מסגנון `emergency`, ואם אין כזו, את החדשה ביותר מסגנון `notice`.

## 5. ‏API

| Method | Path                                      | הרשאה  | תיאור                                                                        |
| ------ | ----------------------------------------- | ------ | ---------------------------------------------------------------------------- |
| GET    | `/api/v1/orgs/:orgId/alerts`              | VIEWER | ההתראות הפעילות ו-20 האחרונות                                                |
| POST   | `/api/v1/orgs/:orgId/alerts`              | EDITOR | הפעלה. גוף הבקשה: `{ style, title, message?, screenIds?, durationMinutes? }` |
| POST   | `/api/v1/orgs/:orgId/alerts/:alertId/end` | EDITOR | סיום                                                                         |

- **בדיקת מסכים:** ‏`screenIds` נבדק מול מסכי הארגון בלבד. מזהה של מסך זר מחזיר 400.
- **Manifest:** נוסף לו השדה `alert: { id, style, title, message, endsAt } | null`. הוא אופציונלי, כך שנגנים ישנים מתעלמים ממנו.

## 6. Threat Model קצר

| איום                             | בקרה                                                                                      |
| -------------------------------- | ----------------------------------------------------------------------------------------- |
| הפעלה זדונית (חשבון שנפרץ)       | הרשאת EDITOR, יומן ביקורת, ומגבלת קצב: 10 הפעלות בדקה לארגון                              |
| ‏IDOR: התראה למסכים של ארגון אחר | ‏`screenIds` מסונן לפי `org_id`, ו-`orgGuard` על כל נתיב                                  |
| ‏XSS במסך                        | ‏`textContent` בלבד                                                                       |
| התראה "תקועה" במסך               | `endsAt` נבדק בנגן. הסיום נשלח ב-WebSocket, וגם בבדיקה התקופתית של ה-Manifest (כל 5 דקות) |

## 7. נגישות

**במסך הניהול:**

- כפתורי התבניות גדולים.
- תיבת אישור לפני הפעלה.
- סטטוס פעיל בולט, שמבוסס גם על טקסט וסמל ולא על צבע בלבד.
- ההודעות מוכרזות ב-`aria-live`.

**בנגן:**

- טקסט גדול שמותאם לגודל המסך.
- ניגודיות לבן על אדום כהה (`#991b1b`), ‏8.3:1.
- בלי הבהוב כשמוגדרת אצל המשתמש העדפה להפחתת תנועה. גם בלעדיה, ההבהוב איטי ממגבלת 3 הבזקים בשנייה (WCAG 2.3.1).

## 8. בדיקות

- **יחידה:** בחירת ההתראה למסך; פקיעת תוקף בנגן.
- **‏API:** הרשאות, בידוד ארגונים, ‏Manifest עם התראה ובלעדיה, יומן ביקורת ומגבלת התראות פעילות.
- **‏E2E:** הפעלה ממסך הניהול, המסך מציג את ההתראה תוך שניות, סיום, והמסך חוזר לתוכן. ‏axe על דף ההתראות.

## 9. תוצאות

- **שרת:**
  - מיגרציה `0010_alerts`, ‏`modules/alerts` (נתיבים ובחירת ההתראה למסך), ושדה `alert` ב-Manifest.
  - הודעת `manifest.changed` נשלחת רק למסכים שההתראה מכוונת אליהם.
  - מגבלות: 10 הפעלות בדקה ו-20 התראות פעילות לארגון.
  - יומן ביקורת: `alert.started` ו-`alert.ended`.
- **נגן:**
  - שכבה מעל הבמה, שמסתובבת יחד איתה.
  - ההתראה מוצגת **לפני** הורדת המדיה, ונשמרת ב-localStorage.
  - הסיום נבדק כל שנייה לפי השעון המתוקן, גם בלי רשת.
  - נבדק בצילומי מסך: חירום (`#991b1b`, ‏8.3:1) והודעה (`#92400e`, ‏7.1:1).
- **מסך הניהול:**
  - דף "התראות חירום" בתפריט: תבניות, סוג, מסכים נבחרים, משך, תיבת אישור, סיום והיסטוריה.
  - צורות זוגי בעברית: "שני מסכים", "שעתיים".
- **בדיקות:**
  - יחידה: בחירת ההתראה למסך ופקיעת תוקף (shared ו-server).
  - ‏API: 4 בדיקות שמכסות מיקוד, אירועי WebSocket, בידוד, ולידציה ותקרה, וגם הצטרפות לבדיקת בידוד הארגונים.
  - נגן: 3 בדיקות. הצגה לפני הורדה, סיום בזמן גם בלי רשת, וטקסט בלבד בלי HTML.
  - מסך הניהול: 2 בדיקות.
  - ‏E2E: התראה למסך אחד מוצגת תוך 10 שניות, וחוזרת לתוכן אחרי הסיום. ‏axe רץ לפני ההפעלה ואחריה.
