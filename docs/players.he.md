# התקנת נגנים

[English](players.md)

כל נגן של Rubinny מציג את אותו נגן Web, שמגיע **מהשרת שלכם** בכתובת
`https://<הדומיין-שלכם>/player/`. עדכון של הנגן מגיע לכל המסכים לבד.

העטיפות שבהמשך מוסיפות רק את מה שדפדפן לא יודע לעשות בעצמו:

- **הפעלה:** עולות יחד עם המכשיר.
- **מסך:** נשארות במסך מלא, והמסך לא נכבה.
- **התאוששות:** חוזרות לבד אחרי קריסה.
- **צילום מסך מרחוק:** במקומות שמצוין.

| מכשיר                          | מה להתקין                           | צילום מסך מרחוק |
| ------------------------------ | ----------------------------------- | :-------------: |
| כל דפדפן מודרני                | [דפדפן](#דפדפן)                     |        —        |
| מחשב Windows / Linux, ‏Mini-PC | [אפליקציית מחשב](#אפליקציית-מחשב)   |        ✓        |
| ‏Raspberry Pi 4 / 5            | [קיוסק Raspberry Pi](#raspberry-pi) |        —        |

**צימוד, בכל המכשירים:**

1. המסך מציג קוד בן 6 תווים.
2. בלוח הניהול נכנסים ל-**מסכים › הוספת מסך** ומקלידים את הקוד.

מכאן המסך שומר אצלו מפתח מכשיר, ולא צריך להגדיר בו שום דבר נוסף.

**מסך לאורך או הפוך:** בוחרים את כיוון המסך בלוח הניהול (**מסכים › עריכה › כיוון מסך**). הנגן מסובב את התוכן בעצמו בכל מכשיר, כך שאין מה להגדיר במכשיר עצמו.

**כתובת השרת חייבת להתחיל ב-https:** דומיין אמיתי, עם התעודה האוטומטית שמגיעה עם `deploy/`. מפתח המכשיר נשלח לכתובת הזו, ולכן אסור שיעבור בלי הצפנה.

## דפדפן

1. פותחים את `https://<הדומיין-שלכם>/player/` במסך מלא או במצב קיוסק, למשל: `chromium --kiosk https://<הדומיין>/player/`.
2. מכבים את שומר המסך ואת מצב השינה של המכשיר.

מתאים לניסיון ראשון, ולמכשירים שיש להם מצב קיוסק מובנה.

## אפליקציית מחשב

האפליקציה **Rubinny Player** (`apps/desktop`, ‏Electron):

- נפתחת במסך מלא ושומרת שהמסך לא ייכבה.
- עולה יחד עם המחשב.
- נטענת מחדש אחרי קריסה, או אם הרשת לא הייתה זמינה כשהמחשב עלה.
- יודעת לשלוח צילום מסך אמיתי ללוח הניהול.

**התקנה:**

1. מורידים את קובץ ההתקנה למערכת שלכם:
   - **‏Windows:** ‏`rubinny-player-<גרסה>-x64.exe`.
   - **‏Linux:** ‏`.AppImage` או `.deb`.

   **מאיפה מורידים:** עד שיפורסמו גרסאות חתומות, ה-CI בונה את הקבצים בכל שינוי. הם נמצאים ב-GitHub › Actions › CI › ההרצה האחרונה › _Artifacts_.

   **או בונים בעצמכם:** `pnpm --filter @rubinny/desktop dist:linux`, או `dist:win` ב-Windows.

2. מפעילים. בהפעלה הראשונה האפליקציה מבקשת את כתובת השרת (`https://signage.example.com`).
3. מצמדים את המסך.

**טוב לדעת:**

- **קיצורי מקלדת למנהל:**
  - `Ctrl+Shift+Alt+S` חוזר לעמוד כתובת השרת.
  - `Ctrl+Shift+Alt+Q` סוגר את האפליקציה.
- **אזהרת SmartScreen ב-Windows:** מופיעה כי קובץ ההתקנה עדיין לא חתום. כדי להמשיך: _מידע נוסף › הפעל בכל זאת_.
- **מחשב בלי מעבד גרפי** (חלק מהמכונות הווירטואליות): אם צילומי המסך יוצאים שחורים או נכשלים, מפעילים את האפליקציה עם משתנה הסביבה `RUBINNY_DISABLE_GPU=1`.
- **התקנה מנוהלת:** אפשר להגדיר מראש את כתובת השרת עם `RUBINNY_SERVER_URL=https://…`.
- **אבטחה:**
  - **אתרים:** האפליקציה מציגה רק עמודים מהשרת שהוגדר, וחוסמת אתרים אחרים וחלונות קופצים.
  - **הרשאות:** כל בקשת הרשאה (מצלמה, מיקום וכו') נדחית.
  - **גישה למחשב:** לעמוד אין שום גישה למחשב. היוצא מן הכלל היחיד הוא צילום של החלון שלו עצמו.

## Raspberry Pi

סקריפט אחד הופך Raspberry Pi 4 או 5 למסך ייעודי:

- **בהדלקה:** ‏Chromium פותח את הנגן במסך מלא, על קומפוזיטור הקיוסק **cage** ‏(Wayland).
- **הרשאות:** הכול רץ תחת משתמש בלי הרשאות.
- **התאוששות:** אם משהו נעצר, הוא עולה מחדש.

**התקנה:**

1. מתקינים **Raspberry Pi OS ‏(64-bit) ‏Bookworm ומעלה** עם Raspberry Pi Imager. גרסת Lite מספיקה.

   בהגדרות של Imager:
   - מפעילים SSH **עם מפתח ציבורי**.
   - מגדירים Wi-Fi, אם צריך.

2. מעתיקים את הסקריפט ל-Pi ומריצים:

   <div dir="ltr">

   ```bash
   scp deploy/kiosk/raspberry-pi/install.sh <user>@<pi-address>:
   ssh <user>@<pi-address>
   sudo ./install.sh --url https://signage.example.com --auto-updates --watchdog
   sudo reboot
   ```

   </div>

3. מצמדים את המסך.

| אפשרות           | מה היא עושה                                           |
| ---------------- | ----------------------------------------------------- |
| `--url`          | כתובת שרת Rubinny שלכם (https בלבד). חובה.            |
| `--auto-updates` | מתקינה `unattended-upgrades` לעדכוני אבטחה אוטומטיים. |
| `--watchdog`     | מפעילה watchdog חומרתי: ‏Pi שנתקע מופעל מחדש לבד.     |
| `--dry-run`      | מדפיסה כל פקודה וכל קובץ, בלי לשנות שום דבר.          |
| `--uninstall`    | מסירה את הקיוסק. המשתמש `rubinny` נשאר.               |

**שימוש שוטף:**

- **החלפת שרת בהמשך:** עורכים את `/etc/rubinny-kiosk.conf`, ואז מריצים `sudo systemctl restart rubinny-kiosk`.
- **לוגים:** `journalctl -u rubinny-kiosk`.
- **הרצה חוזרת של הסקריפט בטוחה**, למשל כדי לשנות אפשרויות.

**מה הסקריפט משנה:**

- **התקנה:** ‏`cage`, ‏Chromium וגופנים.
- **משתמש:** יוצר את המשתמש `rubinny`.
  - בלי סיסמה, בלי shell להתחברות ובלי sudo.
  - שייך רק לקבוצות video, ‏render, ‏input ו-audio.
- **קבצים:**
  - ‏`/etc/rubinny-kiosk.conf`
  - ‏`/usr/local/bin/rubinny-kiosk`
  - ‏`/etc/pam.d/rubinny-kiosk`
  - ‏`rubinny-kiosk.service` על המסוף הראשון (tty1), במקום מסך ההתחברות שלו.
- **כיבוי מסך:** מוסיף `consoleblank=0` לפרמטרים של הקרנל, כדי שהמסך לא ייכבה אף פעם.

**מגבלות ובדיקות:**

- **צילום מסך מרחוק** עדיין לא זמין ב-Pi, כי ל-Chromium אין גשר בטוח לזה.
- **מה נבדק:**
  - ‏ShellCheck.
  - התקנה והסרה אמיתיות בקונטיינר Debian.
  - ‏`systemd-analyze verify`.
  - ה-launcher רץ ב-cage אמיתי עם Chromium.
- **מה עוד לא נבדק:** חומרת Raspberry Pi אמיתית (ראו [תוצאות שלב 8](phases/08-wrappers.md)).
