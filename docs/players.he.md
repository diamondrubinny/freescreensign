# התקנת נגנים

[English](players.md)

כל נגן של Rubinny מציג את אותו נגן Web, שמגיע **מהשרת שלכם** בכתובת
`https://<הדומיין-שלכם>/player/`. עדכון של הנגן מגיע לכל המסכים לבד.

העטיפות שבהמשך מוסיפות רק את מה שדפדפן לא יודע לעשות בעצמו:

- **הפעלה:** עולות יחד עם המכשיר.
- **מסך:** נשארות במסך מלא, והמסך לא נכבה.
- **התאוששות:** חוזרות לבד אחרי קריסה.
- **צילום מסך מרחוק:** במקומות שמצוין.

| מכשיר                               | מה להתקין                                  | צילום מסך מרחוק |
| ----------------------------------- | ------------------------------------------ | :-------------: |
| כל דפדפן מודרני                     | [דפדפן](#דפדפן)                            |        —        |
| מחשב Windows / Linux, ‏Mini-PC      | [אפליקציית מחשב](#אפליקציית-מחשב)          |        ✓        |
| ‏Raspberry Pi 4 / 5                 | [קיוסק Raspberry Pi](#raspberry-pi)        |        —        |
| ‏Android 8.0+, ‏Android TV, טאבלטים | [אפליקציית Android](#android-ו-android-tv) |        ✓        |
| מסכי Samsung ‏(2020+) ו-LG ‏webOS   | [Samsung ו-LG](#מסכי-samsung-ו-lg)         |        —        |

**צימוד, בכל המכשירים:**

1. המסך מציג קוד בן 6 תווים.
2. בלוח הניהול נכנסים ל-**מסכים › הוספת מסך** ומקלידים את הקוד.

מכאן המסך שומר אצלו מפתח מכשיר, ולא צריך להגדיר בו שום דבר נוסף.

**מסך לאורך או הפוך:** בוחרים את כיוון המסך בלוח הניהול (**מסכים › עריכה › כיוון מסך**). הנגן מסובב את התוכן בעצמו בכל מכשיר, כך שאין מה להגדיר במכשיר עצמו.

**כתובת השרת חייבת להתחיל ב-https:** דומיין אמיתי, עם התעודה האוטומטית שמגיעה עם `deploy/`. מפתח המכשיר נשלח לכתובת הזו, ולכן אסור שיעבור בלי הצפנה.

## דפדפן

1. פותחים את `https://<הדומיין-שלכם>/player/` במסך מלא או במצב קיוסק, למשל: `chromium --kiosk https://<הדומיין>/player/`.
2. מכבים את שומר המסך ואת מצב השינה של המכשיר.

מתאים לניסיון ראשון, ולמכשירים שיש להם מצב קיוסק מובנה.

## אפליקציית מחשב

האפליקציה **Rubinny Player** (`apps/desktop`, ‏Electron):

- נפתחת במסך מלא ושומרת שהמסך לא ייכבה.
- עולה יחד עם המחשב.
- נטענת מחדש אחרי קריסה, או אם הרשת לא הייתה זמינה כשהמחשב עלה.
- יודעת לשלוח צילום מסך אמיתי ללוח הניהול.

**התקנה:**

1. מורידים את קובץ ההתקנה למערכת שלכם:
   - **‏Windows:** ‏`rubinny-player-<גרסה>-x64.exe`.
   - **‏Linux:** ‏`.AppImage` או `.deb`.

   **מאיפה מורידים:** עד שיפורסמו גרסאות חתומות, ה-CI בונה את הקבצים בכל שינוי. הם נמצאים ב-GitHub › Actions › CI › ההרצה האחרונה › _Artifacts_.

   **או בונים בעצמכם:** `pnpm --filter @rubinny/desktop dist:linux`, או `dist:win` ב-Windows.

2. מפעילים. בהפעלה הראשונה האפליקציה מבקשת את כתובת השרת (`https://signage.example.com`).
3. מצמדים את המסך.

**טוב לדעת:**

- **קיצורי מקלדת למנהל:**
  - `Ctrl+Shift+Alt+S` חוזר לעמוד כתובת השרת.
  - `Ctrl+Shift+Alt+Q` סוגר את האפליקציה.
- **אזהרת SmartScreen ב-Windows:** מופיעה כי קובץ ההתקנה עדיין לא חתום. כדי להמשיך: _מידע נוסף › הפעל בכל זאת_.
- **מחשב בלי מעבד גרפי** (חלק מהמכונות הווירטואליות): אם צילומי המסך יוצאים שחורים או נכשלים, מפעילים את האפליקציה עם משתנה הסביבה `RUBINNY_DISABLE_GPU=1`.
- **התקנה מנוהלת:** אפשר להגדיר מראש את כתובת השרת עם `RUBINNY_SERVER_URL=https://…`.
- **אבטחה:**
  - **אתרים:** האפליקציה מציגה רק עמודים מהשרת שהוגדר, וחוסמת אתרים אחרים וחלונות קופצים.
  - **הרשאות:** כל בקשת הרשאה (מצלמה, מיקום וכו') נדחית.
  - **גישה למחשב:** לעמוד אין שום גישה למחשב. היוצא מן הכלל היחיד הוא צילום של החלון שלו עצמו.

## Raspberry Pi

סקריפט אחד הופך Raspberry Pi 4 או 5 למסך ייעודי:

- **בהדלקה:** ‏Chromium פותח את הנגן במסך מלא, על קומפוזיטור הקיוסק **cage** ‏(Wayland).
- **הרשאות:** הכול רץ תחת משתמש בלי הרשאות.
- **התאוששות:** אם משהו נעצר, הוא עולה מחדש.

**התקנה:**

1. מתקינים **Raspberry Pi OS ‏(64-bit) ‏Bookworm ומעלה** עם Raspberry Pi Imager. גרסת Lite מספיקה.

   בהגדרות של Imager:
   - מפעילים SSH **עם מפתח ציבורי**.
   - מגדירים Wi-Fi, אם צריך.

2. מעתיקים את הסקריפט ל-Pi ומריצים:

   <div dir="ltr">

   ```bash
   scp deploy/kiosk/raspberry-pi/install.sh <user>@<pi-address>:
   ssh <user>@<pi-address>
   sudo ./install.sh --url https://signage.example.com --auto-updates --watchdog
   sudo reboot
   ```

   </div>

3. מצמדים את המסך.

| אפשרות           | מה היא עושה                                           |
| ---------------- | ----------------------------------------------------- |
| `--url`          | כתובת שרת Rubinny שלכם (https בלבד). חובה.            |
| `--auto-updates` | מתקינה `unattended-upgrades` לעדכוני אבטחה אוטומטיים. |
| `--watchdog`     | מפעילה watchdog חומרתי: ‏Pi שנתקע מופעל מחדש לבד.     |
| `--dry-run`      | מדפיסה כל פקודה וכל קובץ, בלי לשנות שום דבר.          |
| `--uninstall`    | מסירה את הקיוסק. המשתמש `rubinny` נשאר.               |

**שימוש שוטף:**

- **החלפת שרת בהמשך:** עורכים את `/etc/rubinny-kiosk.conf`, ואז מריצים `sudo systemctl restart rubinny-kiosk`.
- **לוגים:** `journalctl -u rubinny-kiosk`.
- **הרצה חוזרת של הסקריפט בטוחה**, למשל כדי לשנות אפשרויות.

**מה הסקריפט משנה:**

- **התקנה:** ‏`cage`, ‏Chromium וגופנים.
- **משתמש:** יוצר את המשתמש `rubinny`.
  - בלי סיסמה, בלי shell להתחברות ובלי sudo.
  - שייך רק לקבוצות video, ‏render, ‏input ו-audio.
- **קבצים:**
  - ‏`/etc/rubinny-kiosk.conf`
  - ‏`/usr/local/bin/rubinny-kiosk`
  - ‏`/etc/pam.d/rubinny-kiosk`
  - ‏`rubinny-kiosk.service` על המסוף הראשון (tty1), במקום מסך ההתחברות שלו.
- **כיבוי מסך:** מוסיף `consoleblank=0` לפרמטרים של הקרנל, כדי שהמסך לא ייכבה אף פעם.

**מגבלות ובדיקות:**

- **צילום מסך מרחוק** עדיין לא זמין ב-Pi, כי ל-Chromium אין גשר בטוח לזה.
- **מה נבדק:**
  - ‏ShellCheck.
  - התקנה והסרה אמיתיות בקונטיינר Debian.
  - ‏`systemd-analyze verify`.
  - ה-launcher רץ ב-cage אמיתי עם Chromium.
- **מה עוד לא נבדק:** חומרת Raspberry Pi אמיתית (ראו [תוצאות שלב 8](phases/08-wrappers.md)).

## Android ו-Android TV

אפליקציית **Rubinny Player** ל-Android (`apps/android`) מציגה את הנגן במסך מלא, ב-Android 8.0 ומעלה:

- **מכשירים:** תיבות TV, טלוויזיות חכמות עם Android TV / Google TV, טאבלטים וטלפונים.
- **מסך:** המסך לא נכבה.
- **התאוששות:** חוזרת לבד אחרי קריסה.
- **צילום מסך:** יודעת לשלוח צילום מסך אמיתי ללוח הניהול.

**התקנה:**

1. **מורידים את קובץ ה-APK:** עד שתפורסם גרסה חתומה, ה-CI בונה APK לדיבוג בכל שינוי באפליקציה. הוא נמצא ב-GitHub › Actions › Android › ההרצה האחרונה › _Artifacts_ › `rubinny-player-android-debug`.
2. **מתקינים:** מאשרים התקנה ממקורות לא ידועים למנהל הקבצים או לדפדפן. או, ממחשב: `adb install app-debug.apk`.
3. **מתחברים:** פותחים את **Rubinny Player**, מזינים את כתובת השרת, ומצמדים את המסך.

**הפעלה עם המכשיר:** ב-Android 10 ומעלה יש הגבלות על אפליקציות שנפתחות לבד. יש שתי דרכים:

- **הכי טוב:** בוחרים ב-Rubinny Player כ-**אפליקציית הבית** (הגדרות › אפליקציות › אפליקציות ברירת מחדל › אפליקציית בית). כך המכשיר תמיד פותח את הנגן, גם אחרי לחיצה על "בית".
- **או:** בעמוד ההגדרה לוחצים על **אישור הצגה מעל אפליקציות אחרות**, ואז הנגן נפתח אחרי הפעלה מחדש.
  - בהרבה מכשירי TV אין את ההגדרה הזו. שם בוחרים באפשרות של אפליקציית הבית.

**טוב לדעת:**

- **גישת מנהל:** לוחצים על **"חזרה" חמש פעמים ברצף** כדי לחזור לעמוד ההגדרה. חוץ מזה, "חזרה" אף פעם לא יוצא מהנגן.
- **אבטחה:**
  - **אתרים:** האפליקציה מציגה רק עמודים מהשרת שלכם. אתרים אחרים מותרים רק בתוך המסגרת של ווידג'ט "דף אינטרנט", ואף פעם לא מקבלים גישה לצילום המסך.
  - **הרשאות:** כל בקשת הרשאה נדחית.
  - **גיבוי:** המידע של האפליקציה, כולל מפתח המכשיר, לא נכלל בגיבויים ובהעברה למכשיר אחר.
- **גרסת דיבוג:**
  - **חתימה:** קובץ ה-APK מה-CI חתום במפתח דיבוג.
  - **בדיקה מרחוק:** הוא מאפשר לבדוק את העמוד דרך USB debugging.
  - **גרסה לחנויות:** גרסה חתומה לחנויות לא נכללת בשלב הזה.

## מסכי Samsung ו-LG

> **עדיין לא נבדק על מסך אמיתי.** הנגן נבנה ונבדק מול מנוע הדפדפן של המסכים האלה, אבל כל צעד בהמשך **דורש אימות מול התיעוד הרשמי** של Samsung ושל LG, ובדיקה על מכשיר. נשמח לשמוע מה עובד.

**אילו מסכים:** הנגן צריך Chromium 69 ומעלה.

- **‏Samsung ‏(Tizen):** דגמי 2020 ‏(Tizen 5.5) ומעלה, לפי [טבלת מנועי הדפדפן](https://developer.samsung.com/tv/develop/specifications/web-engine-specifications) של Samsung.
- **‏LG ‏(webOS Signage):** גרסה 6.0 ומעלה. ‏LG לא מפרסמת טבלה כזו למסכי שילוט, והגרסה לקוחה ממקורות של ספקים אחרים.
- **מסכים ישנים יותר לא נתמכים.** מנוע הדפדפן שלהם כבר לא מקבל עדכוני אבטחה. במקומם משתמשים ב[אפליקציית מחשב](#אפליקציית-מחשב) או בתיבת [Android](#android-ו-android-tv).

**אפשרות 1, בלי להתקין כלום (מומלץ במסכי שילוט):** הרבה מסכי שילוט יודעים לפתוח כתובת אינטרנט בעצמם. מכוונים אותם ל-`https://<הדומיין-שלכם>/player/`:

- **‏Samsung:** ‏**URL Launcher** בתפריט המסך.
- **‏LG:** ההגדרה של כתובת אינטרנט או "SI Server" במסך.

השמות והתפריטים משתנים מדגם לדגם. בודקים במדריך של המסך.

**אפשרות 2, אפליקציית הטעינה של Rubinny:** בכל גרסה יש שתי חבילות קטנות. יש בהן רק דף טעינה: הוא מבקש את כתובת השרת פעם אחת, ואחר כך פותח את הנגן מהשרת שלכם. עדכוני הנגן ממשיכים להגיע מהשרת.

- **`rubinny-tv-tizen-<גרסה>-unsigned.wgt` ‏(Samsung):** **לא חתומה.** מסכי Samsung מתקינים רק אפליקציות שחתומות בתעודה שמזכירה את המכשיר.
  1. חותמים ב-**Tizen Studio** ‏(Certificate Manager, תעודת Samsung עם המזהים של המסכים שלכם).
  2. מתקינים דרך Device Manager של Tizen Studio, או בפקודה `tizen`.
  3. ייתכן שצריך להחליף את מזהה החבילה ב-`config.xml` ‏(`RbnyPlayer`) במזהה משלכם.
- **`rubinny-tv-webos-<גרסה>.ipk` ‏(LG):** מתקינים בכלי [`ares-install`](https://www.npmjs.com/package/@webos-tools/cli) של LG על מסך ב-**Developer Mode**, או בדרך שבה דגם השילוט שלכם מתקין אפליקציות.

**שימוש בדף הטעינה:**

1. **הפעלה ראשונה:** מזינים בשלט את כתובת השרת (אפשר גם רק `signage.example.com`; מתקבלת רק כתובת https), ואז **שמירה והתחלה**.
2. **הפעלות הבאות:** הנגן נפתח אחרי 10 שניות. כל לחיצה על מקש עוצרת את הספירה. **החלפת שרת** מחזירה לכתובת.
3. **"חזרה"** בנגן מחזירה לדף הטעינה.

**מה דף הטעינה עוד לא יודע לעשות:** צילום מסך מרחוק, כיבוי והדלקה לפי לוח זמנים, ועדכון של עצמו. בשביל אלה צריך את ממשקי ה-API של היצרנים ומכשיר לבדיקה.

**אבטחה ופרטיות:**

- **קוד:** דף הטעינה לא מריץ קוד מהרשת. הוא רק פותח את הנגן מהשרת שלכם.
- **מידע במסך:** נשמרת רק כתובת השרת. הנגן שומר את מפתח המכשיר שלו, כמו בכל מכשיר.
- **הרשאות רשת:** השרת נבחר על המסך, ולכן הרשאות הרשת של האפליקציה מתירות כל כתובת https. דף הטעינה דוחה כל כתובת אחרת.
